# Help Desk

O Help Desk é um sistema de gerenciamento de chamados desenvolvido para organizar solicitações internas entre funcionários e equipes responsáveis pelo atendimento.

## Sobre o projeto

A aplicação centraliza a abertura, o acompanhamento e a resolução de chamados. Funcionários acompanham suas solicitações, agentes trabalham nas filas dos seus setores e administradores gerenciam a operação e seus cadastros.

## Funcionalidades

- Autenticação com JWT e controle de acesso por perfil
- Abertura, listagem, busca e filtros de chamados
- Atribuição, transferência, comentários e notas internas
- Resolução e reabertura com histórico automático
- Controle inicial de SLA por prioridade
- Notificações e indicadores operacionais
- Administração de usuários, setores e categorias
- Relatórios de volume, resolução e SLA

## Tecnologias

React, TypeScript, Vite, React Router, React Hook Form, Zod, Axios, Node.js, Express, PostgreSQL, Prisma ORM, JWT e bcrypt.
